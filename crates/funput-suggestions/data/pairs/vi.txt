# Vietnamese first syllables and the syllables a reader would bet on after them.
#
# Built by hand for Funput, from no external word list or corpus — which is why it
# carries the project's own licence and can be shipped (see NOTICE.md). Predict
# reads it for the slots the user's own pairs left empty: after the first
# syllable of a line and a space, the bar offers the ones that follow it.
#
# Layout: one first syllable per line, then one to three syllables that follow
# it, likeliest first, all separated by single spaces, lowercase NFC, tone marks
# placed the modern way (`khoẻ`, not `khỏe`; the engine respells for the
# traditional style). Any `#` line is a comment.
#
# What belongs here: a first syllable that, in everyday chat, is followed by one
# of the listed syllables most of the time. Three rules follow from that.
#
# - It is seldom a word on its own. `chuẩn` is nearly always `chuẩn bị`; `vui`,
#   `gọi`, `quán`, `tối` are words, and anything follows a word (`vui quá`, `gọi
#   cho`). A batch of such lines took the wrong rate on `benchmarks/chat-vi.txt`
#   from 11% to 47%. The few listed anyway (`xin`, `hôm`, `bao`) are the ones
#   whose followers still dominate.
# - The words people type that end with it are listed in vi-ends.txt. Predict
#   reads the syllable before the caret, so `cảm ơn` would offer `ơn` after
#   `dũng cảm`; with `dũng cảm` in that file, it says nothing there. A word
#   this file already spells as a line (`bưu điện`, for the line `điện thoại`)
#   needs no entry. A syllable that ends more common words than anyone can
#   list (`bóng`: `đá bóng`, `quả bóng`, `trái bóng`...) still does not belong.
# - It is not one of the syllables anything can follow (`của`, `và`, `là`), a
#   number or a pronoun (`năm`, `bố`).
#
# Offering wrong words is worse than offering none. No proper nouns: Predict
# cannot capitalise `nội` after `Hà`.
#
# Every line is checked by `funput-lexicon-tool/tests/vi_pairs`. That check
# cannot tell whether a line is sharp enough: measure a batch with
# `funput dev suggest` before it merges, and have a second pair of eyes on it.
